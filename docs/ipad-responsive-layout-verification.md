# iPad Responsive Layout Verification

## 2026-09-17 visual checkpoints

At the 1194 × 834 iPad landscape viewport, the primary navigation now preserves the Graceway lockup while showing the language control and a clear menu trigger instead of the crowded inline navigation row. This prevents Korean navigation labels from wrapping or reducing usable touch targets.

The monthly-calendar guidance is rendered in a dedicated bordered guidance region before the date grid. It is no longer placed after the calendar where the iPad browser could paint it across the lower date rows. The compact menu, Home hero, and Events hero remained visually stable at this tablet width.

At 375 × 812, the existing compact header and the monthly calendar both remain readable without horizontal clipping. At 1440 × 900, the full desktop link row remains visible as before and the calendar change does not disturb the public Events page layout.
