# 주간 주보 PDF 자동 게시 구현 계획

## 목표와 운영 전제

교회 담당자가 매주 토요일 저녁 **전용 Google Drive 폴더**에 PDF 주보를 올리면, 일요일 아침 웹사이트가 해당 폴더의 최신 유효 PDF를 확인해 Graceway의 `/events` 페이지에 게시합니다. 방문자는 최신 주보를 열람·다운로드할 수 있고, 지난 주보도 보관함에서 확인할 수 있습니다. 참조 사이트의 날짜별 주보 목록 경험은 유지하되, Graceway의 네이비·아이보리·절제된 골드 디자인과 현재 행사 페이지 구조에 맞춰 더 간결한 카드형 UI로 구성합니다.

주보 PDF는 공개용 파일이지만, Google Drive 접근 권한은 읽기 전용으로 최소화합니다. PDF의 실제 공개 사본은 웹사이트의 파일 저장소에 복사해 제공하므로, Drive 공유 설정 변경이나 원본 이동으로 공개 링크가 깨지는 위험을 줄입니다.

## 구현 방식 비교

| 접근 방식 | 작동 방식 | 장단점 | 비용 | 초기 설정 |
| --- | --- | --- | --- | --- |
| **정기 자동 동기화 + 사이트 저장소 복사** | 지정 Drive 폴더의 최신 PDF를 일요일 아침에 확인해 사이트 저장소로 복사하고 자동 게시합니다. | 가장 안정적입니다. 공개 Drive 링크가 필요 없고, Drive 원본이 이동·권한 변경되어도 이미 게시된 주보 보관함이 유지됩니다. | 현재 웹사이트의 저장소 사용량만 발생합니다. | Google Cloud 프로젝트, Drive API, 전용 서비스 계정과 폴더 공유가 필요합니다. |
| **정기 자동 동기화 + Drive 링크 표시** | 최신 PDF의 Google Drive 열람 링크만 행사 페이지에 갱신합니다. | 파일 복사가 없어 간단하지만, 원본 파일의 공개 권한·URL이 바뀌면 방문자가 열 수 없게 될 수 있습니다. | 별도 사이트 저장소 사용량이 거의 없습니다. | Drive API 접근과 ‘링크가 있는 모든 사용자’ 열람 권한이 필요합니다. |
| **관리자 수동 업로드** | 담당자가 `/admin`에서 PDF를 올리고 공개합니다. | 외부 연동과 정기 실행이 필요 없어 가장 간단하지만, 매주 담당자가 직접 게시해야 합니다. | 현재 웹사이트 저장소 사용량만 발생합니다. | 별도 API 설정이 없습니다. |

> Google Drive는 변경 알림용 HTTPS 콜백을 제공하지만, 알림 채널이 자동 갱신되지 않으며 `changes` 채널은 최대 7일, 단일 파일 채널은 최대 1일까지만 유지됩니다. 매주 한 번의 예정된 게시에는 주일 아침의 단일·멱등 동기화가 더 단순하고 운영 위험이 낮습니다.[1]

## 자동 동기화 설계안

### 1. 입력 규칙

전용 Google Drive 폴더 하나에 공개할 주보 PDF만 업로드합니다. 파일명은 `2026-09-06_Weekly-Newsletter.pdf`처럼 **발행일(YYYY-MM-DD)**로 시작하는 형식을 권장합니다. 형식이 다를 경우에는 일요일 날짜를 발행일로 사용하되, 관리자 화면에서 날짜와 제목을 수정할 수 있도록 합니다.

현재 제공된 공개 폴더는 로그인 없이 열리며, `2026 0823_주일 주보.pdf`처럼 **연도·MMDD·주일 주보** 형식의 PDF 파일이 주별로 정리되어 있음을 확인했습니다. 자동 동기화는 이 실제 형식을 우선 해석해 가장 최신의 날짜가 있는 PDF를 선택하고, 이후에도 파일명이 일관되게 유지되도록 같은 형식을 운영 표준으로 사용합니다.

공개 폴더의 HTML에는 개별 파일 ID가 포함되며, 확인한 최신 주보 `2026 0823_주일 주보.pdf`는 `1M-Xqga6UDGy2edcEIaaGswteUGnON0tH`로 식별됩니다. 해당 파일은 공개 다운로드 주소에서 인증 없이 `200 application/octet-stream` 응답으로 내려받을 수 있었습니다. 구현은 이 폴더·파일 ID 구조를 읽어 PDF를 웹사이트 저장소에 복사하되, Google Drive의 화면용 HTML이 변경될 가능성을 고려해 관리자 수동 동기화와 기존 공개 주보 유지 장치를 함께 둡니다.

동기화 작업은 `application/pdf` MIME 유형, 삭제되지 않은 파일, 지정 폴더의 직접 하위 파일만 대상으로 삼고 수정 시각 내림차순으로 후보를 확인합니다. Drive API는 폴더·MIME 유형·삭제 상태를 조합한 파일 검색과 `modifiedTime desc` 정렬을 지원합니다.[2]

### 2. 일요일 게시 작업

매주 일요일 **16:00 UTC**에 실행하면 캘리포니아 기준으로 일광절약시간에는 오전 9시, 표준시에는 오전 8시입니다. 두 경우 모두 사용자가 요청한 일요일 아침 게시를 만족하며, 토요일 저녁 업로드 후 검증 여유를 둡니다. 고정 UTC 스케줄이므로 DST 경계에서 정확히 같은 현지 시각을 유지해야 하면 연 2회 스케줄을 조정하는 운영 옵션을 제공합니다.

작업은 다음 순서로 동작합니다.

1. Drive 전용 폴더에서 최신 PDF 메타데이터를 확인합니다.
2. 이미 처리한 Drive 파일 ID인지 확인해 중복 게시를 방지합니다.
3. 새 PDF만 서버에서 내려받아 사이트 파일 저장소에 복사합니다.
4. `weekly_newsletter_issues` 레코드를 생성하거나 갱신하고, 제목·발행일·원본 파일 ID·파일 URL·공개 상태·동기화 시각을 기록합니다.
5. 새 주보가 정상 검증된 경우에만 공개 상태로 전환합니다. 새 파일이 없거나 동기화가 실패하면 기존에 공개된 최신 주보는 그대로 유지합니다.

작업은 재시도되어도 동일 파일을 중복 저장·공개하지 않도록 멱등적으로 만듭니다. 실패 로그와 마지막 성공 시각은 관리자 화면에서 확인하고, 관리자는 필요할 때 **지금 동기화** 또는 **수동 업로드·공개·숨김**을 실행할 수 있습니다.

### 3. 데이터와 권한

`weekly_newsletter_issues` 전용 테이블을 추가합니다. 핵심 필드는 `id`, `issueDate`, `titleKo`, `titleEn`, `driveFileId`(고유), `storageKey`, `storageUrl`, `sourceModifiedAt`, `status(draft|published|hidden)`, `syncedAt`, `publishedAt`, `createdBy`, `createdAt`, `updatedAt`입니다. 파일 바이트는 데이터베이스에 저장하지 않습니다.

공개 API는 `published` 상태의 최신 1건과 보관함 목록만 반환합니다. 파일 동기화·수동 게시·숨김·제목 변경은 관리자 권한에서만 가능합니다. Drive 자격 증명은 서버 비밀값으로만 관리하며, 브라우저·소스 코드·공개 API 응답에는 노출하지 않습니다.

### 4. 행사 페이지 경험

`/events`의 추천 행사 배너 아래 또는 월간 일정 시작 전, **이번 주 주보** 섹션을 추가합니다. 최신 카드에는 발행일, 제목, ‘주보 보기’, ‘다운로드’ 버튼을 표시하고 PDF는 새 탭에서 안전하게 열립니다. 보관함은 최근 12주를 우선 표시하고, 필요 시 더 보기로 확장합니다. PDF가 아직 없을 때는 오류처럼 보이지 않도록 ‘이번 주 주보를 준비 중입니다’ 상태를 표시합니다.

관리자 `/admin`에는 **Weekly Newsletter** 관리 탭을 추가합니다. 마지막 자동 동기화 시각·결과·발견한 최신 Drive 파일을 보여주고, 수동 동기화와 게시 상태 변경을 제공합니다. 자동 작업이 중단되어도 관리자가 즉시 주보를 게시할 수 있는 대체 경로입니다.

### 5. 검증과 운영 안전장치

데이터베이스 마이그레이션 후, Drive 파일 선택·중복 방지·PDF 검증·실패 시 기존 주보 유지·관리자 권한·공개 상태 필터를 단위 테스트로 검증합니다. 데스크톱·모바일 `/events`와 관리자 주보 관리 화면의 PDF 열람·다운로드·빈 상태를 확인합니다. 자동 작업의 성공·실패 로그도 별도로 점검합니다.

| 확인 항목 | 필요한 이유 | 제안 기본값 |
| --- | --- | --- |
| 자동 동기화 방식 | 저장소 복사형 또는 Drive 링크형에 따라 보안·복원력·설정이 달라집니다. | 정기 자동 동기화 + 사이트 저장소 복사 |
| Drive 전용 폴더 | 다른 파일을 오인해 게시하지 않도록 범위를 제한해야 합니다. | 공개 주보 PDF만 담는 전용 폴더 1개 |
| Drive 접근 권한 | 서버가 폴더의 PDF를 읽으려면 최소 권한이 필요합니다. | 서비스 계정에 폴더 Viewer 권한만 공유 |
| 파일명과 발행일 | 주보 보관함의 날짜를 일관되게 표시해야 합니다. | `YYYY-MM-DD_Weekly-Newsletter.pdf` |
| 게시 시각 | 플랫폼 스케줄은 UTC 기준입니다. | 매주 일요일 16:00 UTC (PT 오전 9시/8시) |
| 공개 보관 범위 | 방문자용 UI와 저장소 관리 기준을 정합니다. | 최신 주보 + 최근 12주 보관함 |

## 승인을 위한 제안

자동화가 목표라면 첫 번째 방식의 승인과 함께, **전용 Google Drive 폴더 링크 또는 ID**, 선택한 Drive 인증 방식(권장: 서비스 계정), 원하는 일요일 게시 시각을 알려 주세요. 인증 설정에는 Google Cloud의 Drive API 사용이 필요하며, 자격 증명은 안전한 서버 비밀값으로만 등록합니다. 폴더·권한 정보가 준비되지 않은 동안에도, 동일한 공개 UI와 관리자 수동 업로드를 먼저 제공하는 단계적 구현도 가능합니다.
